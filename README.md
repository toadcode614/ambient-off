# Ambient Off

Tiny Brave extension that disables YouTube Ambient Mode.

CSS-only content script that hides the `#cinematics` glow element on youtube.com.

## Install
1. Clone: `git clone https://github.com/toadcode614/ambient-off.git`
2. Brave → `brave://extensions` → Toggle **Developer mode**
3. **Load unpacked** → select the `ambient-off` folder

## Why
Ambient mode is the color wash YouTube renders behind the video. This kills it permanently, without JavaScript, surviving YouTube's SPA navigation and design changes.
